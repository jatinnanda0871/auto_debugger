# auto_debugger — Memory Dump Analysis Framework

A plugin-based framework for analyzing memory dumps from firmware IP blocks.

The engine is a black box. Product teams only need to know:
1. How to write analyzer functions
2. How to register them
3. Where to put their files

---

## Repository Layout

```
auto_debugger/
├── engine/              ← core engine (opaque in distribution)
│   ├── models.py        ← Region, Chunk, MemoryView
│   ├── api.py           ← DumpAnalyzer — the full analysis API
│   ├── loader.py        ← dump + map file parsers
│   ├── registry.py      ← ModuleDefinition, ModuleRegistry
│   └── repl.py          ← interactive GDB-style REPL
│
├── sdk/
│   └── __init__.py      ← re-exports DumpAnalyzer, ModuleDefinition, ModuleRegistry
│
├── products/            ← one subfolder per product
│   └── epdc/            ← example product
│       ├── product.py   ← REQUIRED: register() entry point
│       ├── config.py    ← all map key names and constants for this product
│       └── modules/
│           ├── tag_manager/
│           │   └── analyzers.py
│           └── fcc_manager/
│               └── analyzers.py
│
└── main.py              ← entry point
```

## Running

### Automated analysis
```bash
python main.py <dump_folder> <product_id>
```

### Automated analysis + interactive REPL
```bash
python main.py <dump_folder> <product_id> --repl
```

The dump folder must contain:
- One or more `*.dump` files
- Exactly one `*.map` file

All analyzers always run first. `--repl` drops into the interactive session afterwards.

## Dump Folder Format

```
my_dump/
├── memory.map      ← generated by firmware build tool (dump_map_gen)
├── file1.dump
└── file2.dump      ← multiple dump files are merged automatically
```

### Map file format
```
IP::key=0xADDR,0xSIZE
```
Example:
```
TagManager::occupied_tags=0xA0001000,0x000000C0
FccManager::counters=0xA0002000,0x00000080
FccManager::fcc_counter_size=48,0x4
```
Size is in bytes (hex). Entries without a `0x` prefix on the address are literal
values — retrieved with `get_value(key, is_address=False)`.

### Dump file format
```
0xADDR: 0xDW1 0xDW2 0xDW3 0xDW4 0xDW5 0xDW6 0xDW7 0xDW8
```
8 dwords per line, 4-byte aligned addresses.

## Adding a New Product

### Step 1 — Create the product folder

```
products/
└── myproduct/
    ├── __init__.py       ← empty
    ├── product.py        ← required
    ├── config.py         ← required
    └── modules/
        ├── __init__.py   ← empty
        └── tag_manager/
            ├── __init__.py   ← empty
            └── analyzers.py
```

### Step 2 — Write `config.py`

All map key names and constants belong here. Analyzers import from this file.

```python
# products/myproduct/config.py

TAG_OCCUPIED_KEY = "TagManager::occupied_tags"

TAG_PENDING_KEYS = [
    "TagManager::fetch_pending",
    "TagManager::write_pending",
]
```

### Step 3 — Write analyzer functions

Each function receives a `DumpAnalyzer` and returns nothing.

```python
# products/myproduct/modules/tag_manager/analyzers.py

from engine.api import DumpAnalyzer
from products.myproduct.config import TAG_OCCUPIED_KEY, TAG_PENDING_KEYS


def analyze_occupied_tags(analyzer: DumpAnalyzer) -> None:
    print("\n=== Occupied Tags ===")

    missing = analyzer.get_missing_regions(TAG_OCCUPIED_KEY, *TAG_PENDING_KEYS)
    if missing:
        print(f"  [SKIP] Missing regions: {missing}")
        return

    tags = analyzer.get_set_tags(TAG_OCCUPIED_KEY)
    print(f"  Occupied tags: {len(tags)}")
```

### Step 4 — Register in `product.py`

```python
# products/myproduct/product.py

from engine.registry import ModuleRegistry, ModuleDefinition
from products.myproduct.modules.tag_manager.analyzers import analyze_occupied_tags


def register(registry: ModuleRegistry) -> None:
    registry.register_module(ModuleDefinition(
        name      = "TagManager",
        analyzers = [analyze_occupied_tags],
    ))
```

### Step 5 — Run

```bash
python main.py <dump_folder> myproduct
```

## DumpAnalyzer API Reference

### Core access
```python
get_value(key, is_address=True)         # dword at address, or literal value
get_region_dwords(key)                  # all dwords in region as list
get_byte(key, byte_offset)              # single byte within region
get_base_addr(key)                      # base address of region
get_region_size_dwords(key)             # size in dwords
key_exists(key)                         # True if key is in map
```

### Bit / tag operations
```python
is_zero(key)                            # dword == 0
is_bit_set(key, bit)                    # single bit check
get_set_bits(key)                       # list of all set bit positions
get_set_tags(key)                       # alias for get_set_bits
count_set_tags(key)                     # count only, no list
is_tag_set_in_region(key, tag_index)    # check specific tag in bitmap
```

### Bitfield extraction
```python
get_bitfield(key, bit_offset, bit_width)
get_bitfield_at_offset(key, byte_offset, bit_offset, bit_width)
```

### Array iteration
```python
iter_dwords(key)                          # generator: (index, dword)
iter_struct_array(key, struct_size_bytes) # generator: (index, byte_offset)
```

### Aggregation
```python
sum_bitfield_across_region(key, bit_offset, bit_width)
any_nonzero(key)
```

### Cross-region correlation
```python
get_tags_in_all(*keys)                # set intersection
get_tags_in_any(*keys)                # set union
get_tags_only_in(source, *excludes)   # orphan detection
compare_tag_counts(key_a, key_b)      # {count_a, count_b, delta, match}
```

### Validation
```python
assert_equal(label, actual, expected)   # prints [PASS]/[FAIL]
assert_zero(label, key)
assert_no_tags_set(label, key)
```

### Dump coverage
```python
is_region_in_dump(key)
get_missing_regions(*keys)
```

## REPL Commands

| Command | Description |
|---|---|
| `TagManager::occupied_tags` | GDB-style hex dump of region |
| `x/8xw 0xA0001000` | Read N dwords at raw address |
| `x 0xA0001000` | Read 4 dwords at address (default) |
| `list` | List all known regions with dump coverage |
| `run <analyzer_name>` | Run a registered analyzer by name |
| `help` | Show command reference |
| `quit` | Exit session |
